SEECODER 桌面端

界面与 Agent 内核分离

Electron 仅负责本地桌面渲染和交互。它通过受控的本机子进程调用现有 CLI；上下文、工具 schema、文件读写、命令执行、错误处理和停止条件仍全部由 Python 自研实现。

界面不读取、不显示、不持久化 API key，也不会启用 --host-shell。可在 自动 / 计划 / 询问 三种模式下运行：计划模式先给出方案再批准执行，询问模式在每一步写文件或运行命令前征求你的同意。
