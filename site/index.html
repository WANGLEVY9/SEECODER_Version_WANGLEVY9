05 / BOUNDARIES

把风险写进结构，而不是写进愿望。

这些限制不是营销词。它们是工具层、策略层和运行时的实际约束。

01WorkspaceBoundary

路径先过边界

规范化绝对路径并解析符号链接，拒绝越出当前 workspace、敏感文件和受保护目标。

02Policy / Mode

变更需要策略

Ask 在写入或命令前等待批准；Plan 只读并生成计划；Auto 仍受本地工具策略约束。

03restricted argv

命令不默认拼 shell

常见验证命令走字面 argv、超时、进程组终止和敏感环境剥离。

04TraceWriter

事实留下轨迹

事件和 trace 分开表达模型建议、本地结果、错误和终态，并对凭据做脱敏。

!
明确限制：run_command 不是 OS 级沙箱。

工作区边界、黑名单和超时能降低风险，但不能阻止熟悉 shell 的命令访问主机外部资源。演示和真实运行应使用不含凭据的隔离 workspace。
